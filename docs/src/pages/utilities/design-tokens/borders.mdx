# Borders

## Border Widths

The variables for border widths are all prefixed with `--cd-border-`. They're
designed to be used with the `border-width` property.

## Border Radii

The variables for radii are all prefixed with `--cd-radius-`. They're designed to
be used with the `border-radius` property.

<div class="cd-alert cd-status-warning">
  <div class="cd-alert-content">
    <div class="cd-alert-title">Warning</div>

    These tokens, with the exception of `none` and `full`, are designed to be used
    with `corner-shape: squircle`. Failing to set this on an element that uses
    radius tokens will result in its borders looking rounder than intended on
    browsers that support `corner-shape`.
  </div>
</div>
